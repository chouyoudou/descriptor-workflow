# Intrinsic first-shell geometry and directionality

Task: `paper-90e28c3ec503f6631b2ce91d`  
Paper: DOI `10.1107/S1600576723005940`

## Purpose and boundary

The paper motivates a strict separation between **intrinsic geometry visible in
an explicit crystal structure** and **polycrystalline or experimental state
variables**. This implementation accepts an ordered periodic structure (an
ordinary POSCAR/CONTCAR through the CLI) and returns fixed, interpretable
scalars. It does not infer texture, grain size or grain statistics, domain
populations, phase fractions, applied-field/loading history, experimental
strain, frequency, neutron/synchrotron settings, or functional response.

The descriptors are therefore geometry summaries, not surrogates for STRAP,
Rietveld refinement, domain switching, ferroelectric polarization, or a phase
transformation experiment.

## Deterministic first shell

For site `i`, let `d_i,min` be its nearest non-self periodic-image distance.
The selected shell is

```text
d_ij <= 1.25 d_i,min
```

with periodic images generated by
`pymatgen.optimization.neighbors.find_points_in_spheres`. The rule is fixed,
species-blind, and target-blind. It avoids guessed oxidation states or bond
orders, but it remains an adaptive geometric shell rather than a chemically
validated coordination model.

## Fixed feature contract

The schema is `intrinsic-first-shell-directionality/1` and contains 23 named
features in a stable order.

### Coordination and distance

- `first_shell_coordination_mean`, `first_shell_coordination_std`: mean and
  population standard deviation of per-site shell counts.
- `first_shell_distance_mean_angstrom`: mean over directed shell vectors.
- `first_shell_distance_cv`: population standard deviation divided by the mean.

### First-shell distance distortion

For each site, the Baur-style distortion index is

```text
D_i = mean_j |d_ij - mean_j(d_ij)| / mean_j(d_ij)
```

The contract reports the site mean, root-mean-square, and maximum as
`baur_first_shell_distortion_{mean,rms,max}`. The historical Baur definition
is mature; using it with this adaptive first shell and these aggregates is the
project's processing choice.

### Geometric off-centering

For site `i`,

```text
o_i = mean_j(r_ij) / mean_j(|r_ij|)
```

where each `r_ij` is a Cartesian periodic shell vector. The norm of `o_i` is
summarized by mean, RMS, and maximum. The alignment scalar is

```text
|sum_i o_i| / sum_i |o_i|
```

and is a typed null when every local vector has zero norm. These values measure
shell-centroid asymmetry only; they are not polarization or displacement from a
refined crystallographic reference site.

### Rank-2 bond fabric and intrinsic directionality

For unit shell directions `u_n` and nonnegative weights `w_n`,

```text
F = sum_n w_n u_n u_n^T / sum_n w_n
```

The eigenvalues `lambda_1 <= lambda_2 <= lambda_3` are nonnegative and sum to
one. The scalar anisotropy is

```text
q2 = sqrt(3/2 * sum_k (lambda_k - 1/3)^2)
```

and the barycentric decomposition is

```text
linearity = lambda_3 - lambda_2
planarity = 2 (lambda_2 - lambda_1)
isotropy = 3 lambda_1
```

These three contributions sum to one. Ideal limits are: axial pair
`(1,0,0)`, four directions in a plane `(0,1,0)`, and cubic six-direction shell
`(0,0,1)` for `(linearity, planarity, isotropy)`.

The contract reports the global bond fabric, per-site `q2` mean/std, a
bond-count-weighted site mean, and
`site_to_global_q2_cancellation`. The latter is the weighted local `q2` minus
the global `q2`; it indicates cancellation between differently oriented local
environments and is a project-defined heuristic, not a texture measurement.

### Element-conditioned extension

The only elemental lookup is the independently tabulated atomic number `Z`.
For a directed first-shell pair,

```text
c_ij = |Z_i - Z_j| / (Z_i + Z_j)
```

The contract reports the heterochemical shell fraction, mean `c_ij`, a fabric
weighted by `c_ij`, and the shift of weighted `q2` from unweighted `q2`.
Identical-`Z` shells produce typed nulls for the weighted fabric and shift.
Atomic-number contrast is a stable compositional marker, not ionicity, charge
transfer, valence, or bond strength.

## Conditional paired-structure extension

`explicit-paired-structure-change/1` is available only when the caller supplies
two explicit structures and asserts direct lattice correspondence with
`--assume-lattice-correspondence`. It reports principal logarithmic lattice
strains, log-volume strain, a deviatoric Hencky norm, and deltas of features
that are defined in both structures. It performs no atom mapping and does not
decompose lattice strain, phase switching, domain switching, or texture.

## CLI

Single structure:

```bash
python intrinsic_directionality.py POSCAR --output descriptor.json
```

Explicit paired structures:

```bash
python intrinsic_directionality.py reference.POSCAR \
  --target target.POSCAR \
  --assume-lattice-correspondence \
  --output paired.json
```

Exit status `2` returns a JSON object with a typed unavailability reason. NaN
and infinity are never serialized. Partially occupied structures are outside
the fixed descriptor's domain.

## Known limitations

The 1.25-nearest-distance shell may split a chemically familiar coordination
shell or include an undesired close contact when bond lengths are strongly
multimodal. Periodic structures with overlaps, extreme voids, excessive shell
coordination, or unsupported partial occupancy return typed unavailability.
The tensor is even under direction reversal, so it measures axis/fabric
anisotropy rather than polar handedness. Scalar aggregation also discards
site identity and cannot by itself establish a crystal phase.
