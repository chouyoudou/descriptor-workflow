# Spacer–coordination–interfragment packing descriptors

**Task:** `paper-03aef80c9d0a380d998e06d1`  
**Source DOI:** `10.1002/open.202200229`  
**Input contract:** one ordinary, fully occupied POSCAR/CONTCAR  
**Output contract:** each exported descriptor callable returns exactly one finite Python `float`

## Scientific scope freeze

The source article reports dicationic imidazolium compounds with alkyl spacers,
a locally tetrahedral mixed-halide ferrate environment, and explicit crystal
contacts/packing. The transferable structural mechanisms retained here are:

1. graph-resolved spacer extension and the shape of finite bonded fragments;
2. local bonded coordination-shell radial and directional geometry; and
3. non-covalent interfragment contact compactness, coordination, directional
   anisotropy, and element-pair composition.

The implementation does **not** infer formal or partial charge, oxidation state,
spin state, magnetic moment, liquid state, melting point, solubility, thermal
stability, decomposition, synthesis, processing, or any other history-dependent
property. It does not use those measured quantities as labels. The article's
mixed Cl/Br occupancies and dynamic halide exchange are not reconstructed from
a fully occupied POSCAR; the explicit input structure is analyzed as supplied.

## Fixed graph and image protocol

For atom `i`, the lookup radii are `r_cov,i` and `r_vdw,i`. A canonical periodic
atom-image pair `(i, j, n)` has displacement

`d_vec = r_j + n · H - r_i`,

where the rows of `H` are cell.vectors and `n` is an integer image vector. The
pair is a bond-graph edge when

`d <= 1.18 (r_cov,i + r_cov,j)`.

Connected components are unwrapped by propagating edge image vectors. A
non-zero translational inconsistency around a graph cycle marks the component
as periodic. Finite components that merely cross a cell boundary are therefore
not confused with infinite covalent networks.

A non-bonded pair is an interfragment contact when it is not intramolecular in
the same finite component image and

`0.45 <= ρ_ij = d_ij / (r_vdw,i + r_vdw,j) <= 1.05`.

Its fixed closeness weight is

`c_ij = clip((1.05 - ρ_ij) / (1.05 - 0.75), 0, 1)`.

No energetic or interaction-strength meaning is assigned to `c_ij`.

## Scalars

### `spacer_path_extension`

Ring atoms are identified from non-bridge graph edges. Maximal non-ring chains
between graph anchors (ring atoms or nodes of degree other than two), with at
least three bonds, are candidate spacers. For path `p`, contour length is `L_p`
and endpoint distance is `R_p`. The reported scalar is

`E_spacer = Σ_p L_p (R_p/L_p) / Σ_p L_p = Σ_p R_p / Σ_p L_p`.

Range: `[0, 1]`. Higher values indicate straighter resolved spacer paths. Zero
means no qualifying path was resolved, not a physically collapsed chain.

### `spacer_atom_fraction`

Unique internal atoms of qualifying spacer paths divided by all atoms in finite
bonded components. Range: `[0, 1]`.

### `component_shape_anisotropy`

For each finite component with at least three atoms, compute the equal-atom
second moment (gyration) tensor with eigenvalues `λ1, λ2, λ3` and

`κ² = 1 - 3(λ1λ2 + λ2λ3 + λ3λ1)/(λ1 + λ2 + λ3)²`.

The output is component-size-weighted. Range: `[0, 1]`; zero is isotropic in
second moment and one is collinear. This is a geometric component-shape scalar,
not a polymer dynamics quantity.

### `coordination_shell_radial_distortion`

For every atom with at least three bond-graph neighbor images, define
`q_k = d_k/(r_cov,center + r_cov,k)`. The site value is the coefficient of
variation `std(q)/mean(q)`. Site values are coordination-number weighted.
Range: `[0, ∞)`. It is an RMS/CV definition, not the Baur mean-absolute bond
length distortion index.

### `coordination_shell_orientation_anisotropy`

For unit bond directions `u_k`, form

`M = (1/N) Σ_k u_k u_k^T`,

with eigenvalues `μ_a`, and report

`A = (3/2) Σ_a (μ_a - 1/3)²`.

Coordination-number-weighted range: `[0, 1]`. A regular tetrahedral or
isotropically distributed shell has `A≈0`; a collinear shell has `A=1`.
A square-planar shell is directionally anisotropic (`A=0.25`) even when it is
internally symmetric, so this scalar must not be called a universal distortion.

### `interfragment_contact_compactness`

Arithmetic mean of `c_ij` over resolved interfragment contacts. Range: `[0, 1]`.
It characterizes only the selected radius-normalized contact set.

### `interfragment_contact_coordination`

For component `a`, sum contact weights to each distinct neighboring
component-image `b` as `W_ab`, then compute the participation ratio

`N_eff,a = (Σ_b W_ab)² / Σ_b W_ab²`.

The scalar is the mean over contacted components. Range: `[0, ∞)`. This is an
effective number of comparably weighted contacted component images, not an
oxidation-state coordination number.

### `interfragment_contact_anisotropy`

Use the contact-weighted tensor

`M_c = Σ c_ij u_ij u_ij^T / Σ c_ij`

and the same bounded eigenvalue invariant `A`. Range: `[0, 1]`; zero is
second-moment isotropy and one is collinear contact packing.

### `heteroelement_contact_fraction`

`Σ c_ij I(element_i != element_j) / Σ c_ij`. Range: `[0, 1]`. This is explicit
element identity binding, not ionic character or charge transfer.

### `contact_pair_specificity`

Group contact weight by unordered element pair. For non-zero pair probabilities
`p_k`, compute normalized Shannon specificity

`S_pair = 1 - [-Σ p_k ln p_k]/ln(K)`.

Range: `[0, 1]`. One means a single pair class dominates; zero means equal
weight over the observed pair classes. No contacts return zero.

## Interface

```python
from molecular_packing_descriptor import spacer_path_extension
value = spacer_path_extension("POSCAR")
assert type(value) is float
```

Each function in `DESCRIPTOR_FUNCTIONS` accepts one POSCAR path and returns one
finite scalar. `compute_all()` is a convenience helper, not the scalar contract.
The CLI writes one descriptor value:

```bash
python -m molecular_packing_descriptor POSCAR \
  --descriptor interfragment_contact_anisotropy \
  --output output/paper-03aef80c9d0a380d998e06d1/result.json
```

## Invariances and defined fallbacks

The scalars are invariant, within floating-point tolerance, to whole-structure
translation, element-block ordering, atom ordering within blocks, and integer
supercell replication. Rotation of both cell and coordinates leaves distance
and eigenvalue invariants unchanged.

No qualifying spacer, shell, or contact set returns `0.0`. Malformed POSCARs,
unknown element symbols, singular cells, and structures that exceed the fixed
periodic-image/pair safety budget raise `DescriptorError`. Values are never
silently returned as NaN or infinity.

## Known risks

- Radius-threshold bond perception cannot uniquely distinguish covalent,
  coordinative, and ionic connectivity for every chemistry.
- A fully occupied POSCAR cannot represent the source article's mixed halide
  occupancy without an explicit ordered model supplied by the user.
- Very small or extremely skewed cells may require more periodic images than
  the fixed safety limit and are rejected rather than approximated.
- Contact closeness is a geometry score. It is not interaction energy,
  hydrogen-bond strength, lattice energy, or a liquid-state observable.
- Fragment-based scalars intentionally return conservative zeros for unresolved
  infinite bonded networks; they are designed primarily for molecular and
  molecular-ionic crystals.
