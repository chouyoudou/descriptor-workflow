# Periodic Ring–Layer Topology (PRLT)

`descriptors.periodic_ring_layer` provides a fixed 24-scalar static structure
descriptor for ordinary VASP 5 POSCAR files and equivalent periodic structure
records.  It combines:

- neutral-covalent-radius periodic graph construction;
- connected-component translation rank (`0..3`);
- bounded zero-winding shortest-path rings through length 12;
- least-squares ring planarity and rank-two layer geometry; and
- categorical element assortativity plus neutral lookup contrasts.

It does not infer bond order, oxidation state, charge, electronic structure,
energy, kinetics, synthesis history, finite-particle morphology, or application
performance.  Radius-admitted graph edges are geometric contacts, not asserted
chemical bonds.

## Command line

The pinned execution environment already contains NumPy, SciPy, and RDKit.

```bash
python -m descriptors.periodic_ring_layer examples/POSCAR_prlt_checkerboard
```

For a JSON object, use `--json`.  The accepted fields are `lattice`, `species`,
and `fractional_coordinates`.

## Public API

```python
from descriptors.periodic_ring_layer import analyze_structure, parse_poscar

structure = parse_poscar("POSCAR")
row = analyze_structure(structure)
print(row["status"])
print(row["scalars"])
```

Every row has a fixed scalar key set.  Unsupported domains and declared resource
limits are represented by `None` plus `unavailable_reasons`; they are not silently
filled with zeros or a partial ring distribution.

## Method summary

A periodic edge `(i,j,n)` is admitted when

```text
0.45 Å <= d(i,j,n) <= 7.50 Å
and d(i,j,n) / (r_i + r_j) <= 1.20,
```

using RDKit neutral covalent radii.  Component rank is the rank of independent
integer lattice translations generated by cycle closures.  A ring is admitted only
when it is simple, zero-winding, no longer than 12, and no pair of its states has a
graph path strictly shorter than the shorter ring arc.  Rings are deduplicated under
translation, cyclic rotation, and reversal.

The ring criterion follows the shortest-path-ring concept introduced by Franzblau,
while periodic localization, resource policy, geometry, element coupling, and fixed
aggregation are this implementation's processing definitions.  Translation-rank
analysis is related to the periodic component method of Larsen and co-workers.
Categorical element assortativity uses Newman's mixing-matrix coefficient.

## Related names that are not aliases

A shortest-path ring is stricter than merely chordless when a multi-edge external
shortcut exists.  A cycle basis, minimum cycle basis, and chemistry SSSR are
independent cycle-space selections rather than the complete local shortest-path-ring
set.  PRLT does not label these as equivalent.

## Reproducibility

The implementation is invariant-tested for origin shifts, atom permutations,
Cartesian rotations, unimodular basis changes, and diagonal supercells.  Dense or
pathological graphs activate deterministic guards; in that case ring-distribution
channels are null rather than computed from a biased prefix.
