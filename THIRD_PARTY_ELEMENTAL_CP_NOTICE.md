# Third-party notice: matminer Magpie elemental heat-capacity table

`elemental_reference_heat_capacity.py` embeds the finite rows of
`HeatCapacityMolar.table` from matminer 0.10.1, pinned to commit
`25cd8f2778d73e54f80b38ee1983a28643368118`.

The accompanying upstream README describes the table as molar heat capacity at
STP, in J/mol-K, sourced from the CRC Handbook.
